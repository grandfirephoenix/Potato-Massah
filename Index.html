Quick Start & Installation

Up and running in under a minute—no AutoHotkey installation required for the standalone release.

Running Standalone Potato Massah.exe

Windows 10 / 11 (64-bit)
1

Verify VoiceMeeter Potato

Ensure VoiceMeeter Potato (64-bit) is installed so VoicemeeterRemote64.dll is available in its default VB-Audio directory.

2

Download & Launch .EXE

Download Potato Massah.exe into its own folder and launch it. Your custom pinch-knob icon appears in the system tray immediately.

3

Select Strip & Roll Wheel

Press Ctrl + Alt + V to toggle the Control Panel. All labels, targets, and keybinds persist automatically to volume_settings.ini.

Source Build Compiling from PotatoMassah.ahk via Ahk2Exe U64

To run directly from source or build your own binary, install AutoHotkey v2.0+ (64-bit) and open Ahk2Exe:

  • Place Potato.ico (or icon.ico) in the same folder as PotatoMassah.ahk.
  • Set Base File (.bin/.exe) to v2.0.x U64 AutoHotkey64.exe—a 64-bit base binary is required so Windows can load VoicemeeterRemote64.dll.
